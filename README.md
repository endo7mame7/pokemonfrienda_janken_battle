# pokemonfrienda_janken_battle

ポケモンフレンダのピックを使ったジャンケン型対戦ゲームです。
幼稚園児2人が1台のiPhoneで向かい合って遊ぶことを想定した、Webアプリのプロトタイプです。

## 遊び方

1. `index.html` を iPhone の Safari で開く（ホーム画面に追加すると全画面で起動できます）
2. 「ピックずかん」で手持ちのピックを撮影して登録する
   - よこむき／たてむきの枠に合わせて、1本指で移動、2本指で拡大・回転
   - 傾きスライダーと90°回転で微調整し、ピックの形で切り抜いて保存
   - なまえ・タイプ（18種類）・わざの なまえ を入力
3. ホームで「あか」「あお」のピックを選んで「バトル スタート！」
4. iPhoneを2人の間に置き、それぞれ自分側の手（グー・チョキ・パー）を長押しして決める
5. じゃんけんに勝つと、カットインのあとピックが技モーションで攻撃。ハート3つを先に削った方の勝ち

## ドキュメント

内部構造・仕様・設計判断の詳細は [docs/design.md](docs/design.md) にまとめています。

## 仕様メモ

- 単一ファイル（HTML/CSS/JavaScript）、外部ライブラリなし（フォントのみ Google Fonts）
- ピック外形：縦横比 約1.62 の角丸長方形、ボールマーク側の角のみ大きい丸み（横向きは左下、縦向きは右下）
- 登録したピック画像は端末内（IndexedDB）にのみ保存。Safariのサイトデータを消すと消えます
- あいこはダメージなしでやり直し。タイプ相性は未実装
- 技エフェクトはタイプごとのパーティクル、効果音は Web Audio、掛け声は音声合成
- 技名の表示は攻撃した側だけに、その子から読める向きで出す
- 最初に入っているサンプルピックは図形で生成したもので、公式画像は含みません

## 公開について

ピック写真には公式イラストが写るため、登録データは端末の外に出ない設計です。
リポジトリにもピック画像は含めていません。
