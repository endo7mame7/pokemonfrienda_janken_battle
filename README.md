# pokemonfrienda_janken_battle

ポケモンフレンダのピックを使ったジャンケン型対戦ゲームです。
幼稚園児2人が1台のiPhoneで向かい合って遊ぶことを想定した、Webアプリのプロトタイプです。

## 遊び方

1. `index.html` を iPhone の Safari で開く（ホーム画面に追加すると全画面で起動できます）
2. 「ピックずかん」で手持ちのピックを撮影して登録する
   - よこむき／たてむきの枠に合わせて、1本指で移動、2本指で拡大・回転
   - 傾きスライダーと90°回転で微調整し、ピックの形で切り抜いて保存
   - なまえ・タイプ（18種類）・わざの なまえ・メガシンカ技と その わざの なまえ を入力
   - 登録ずみのカードを タップすると あとから なおせます（写真はそのままでOK）
3. ホームで人数（1たい1／2たい2／3たい3）を選び、「あか」「あお」のチームを組む
   - 3たい3には ピックが3枚以上 必要（チーム内で同じピックは使えません）
   - すでに使っているピックを選ぶと、その枠と入れ替わります
4. iPhoneを2人の間に置き、それぞれ自分側の手（グー・チョキ・パー）を長押しして決める
5. じゃんけんに勝つと、カットインのあとピックが技モーションで攻撃。ハート3つを先に削った方の勝ち
6. 2たい2・3たい3は勝ち抜き戦。たおれたら次のピックが登場し、先に全員たおされた方の負け
7. きずなゲージが満タンになると じぶんのピックが虹に光る。ピックを長押しすると「メガシンカ する？」が出る

内部構造・仕様・設計判断の詳細は [docs/design.md](docs/design.md) にまとめています。

## 仕様メモ

- 単一ファイル（HTML/CSS/JavaScript）、外部ライブラリなし（フォントのみ Google Fonts）
- ホーム画面の下部に開発用のバージョンを表示（`index.html` の `VERSION` / `BUILD` を手で更新する）
- ピック外形：縦横比 約1.62 の角丸長方形、ボールマーク側の角のみ大きい丸み（横向きは左下、縦向きは右下）
- 登録したピック画像は端末内（IndexedDB）にのみ保存。Safariのサイトデータを消すと消えます
- あいこはダメージなしでやり直し。タイプ相性は未実装
- メガシンカは ずかん登録で技を選んだピックだけ。こうげき1回ぶんで 元の姿にもどる
  - ゲージを溜め直せば 何度でもメガシンカできる（あいこでは消費しない）
  - 効果は10種。ずかんでは こうげき／まもり／じゃま に分けて えらぶ

    | グループ | 技 | 効果 |
    | --- | --- | --- |
    | こうげき | かいしんの いちげき | かつと ハートを 2つ けずる |
    | こうげき | いのちを すいとる | かつと けずって じぶんも 1つ かいふく |
    | こうげき | あらしの ちから | あいこでも あいてを 1つ けずる |
    | こうげき | しかえしの いちげき | まけても あいてを 1つ けずる |
    | まもり | まもりの かべ | まけても ハートが へらない |
    | まもり | ふんばる ちから | ハートが 0に なっても 1つ のこる |
    | まもり | いやしの ひびき | あいこでも ハートが 1つ かいふく |
    | じゃま | てを けす | あいての ては 2つに へる（1つ ✕になる） |
    | じゃま | てを かくす | あいての ては ぜんぶ ❓、ならびも 入れかわる |
    | じゃま | きずなを うばう | かつと あいての きずなが 0に なる |

  - 「てを けす」「てを かくす」は **じゃんけんの前**にはたらく。かけられた側は 手をえらび直す
  - 「いやしの ひびき」は ハートが満タンだと はたらかない（＝メガシンカも 解けない）
  - 古いバージョンの技（v0.10.0 の「もういちど メガシンカ」）を持つピックは
    メガシンカなし あつかいになる。ずかんで なおせば また使える
  - メガシンカ技の なまえは 自由に決められる（未入力なら 効果の名前をそのまま使う）
  - メガシンカは 技がはたらいた時だけ解ける。じゃんけんに負けただけでは 解けない
  - きずなは 負けたときに多く貯まり、貯まり方にランダム係数がかかる
  - 連敗するほど 貯まり方が増える（2連敗すれば かならず満タンになる）
  - 専用の姿は用意せず オーラで表現。解けても副作用はなし
  - メガストーン／メガシンカのイメージに合わせて 演出はすべてレインボー
- ハートは人数にかかわらず3つ。3たい3は最短9ラウンド
- 勝ち抜いたピックのハートは回復しないので、1体で相手チームを全滅させることもできる
- 技エフェクトはタイプごとのパーティクル、効果音は Web Audio、掛け声は音声合成
  - **18タイプすべてに別のエフェクト**（形・飛び方・速さを変えている）
  - ほのお＝炎が立ちのぼる／みず＝しぶき／でんき＝いなずま／くさ＝舞い落ちる葉／
    こおり＝外から集まる結晶／かくとう＝衝撃線／どく＝のぼる泡／じめん＝巻き上がる土／
    ひこう＝横切る羽根／エスパー＝広がる波紋／むし＝ジグザグの群れ／いわ＝重い岩／
    ゴースト＝ただよう人魂／ドラゴン＝渦を巻く三日月／あく＝十字の爪あと／
    はがね＝金属のきらめき／フェアリー＝ゆれるハート／ノーマル＝はじける星
  - メガシンカ技のときだけ タイプに関係なく レインボーの星になる
- 技名の表示は攻撃した側だけに、その子から読める向きで出す
- 勝敗表示は それぞれの子に「◯◯の かち！」「◯◯の まけ」を 自分から読める向きで出す
- 結果画面は 放射光・紙吹雪・王冠つき。チーム戦では 両チームの戦績（たおれたピックは白黒に✕）も出る
- 最初に入っているサンプルピックは図形で生成したもので、公式画像は含みません

## 公開について

ピック写真には公式イラストが写るため、登録データは端末の外に出ない設計です。
リポジトリにもピック画像は含めていません。
